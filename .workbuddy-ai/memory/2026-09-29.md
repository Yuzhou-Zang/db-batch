### 环境坑：沙箱会拦截 `.git/refs/remotes/` 写入

- 推送后 `git status` 出现 `## main...origin/main [gone]`，`git for-each-ref refs/remotes/` 为空 —— 远端跟踪引用**没有落盘**。
- 原因：沙箱拦截了 `.git/refs/remotes/origin/` 目录的创建。`git update-ref` 和 `mkdir -p` 都返回 exit=0 但**静默失败**（不报错也不生效），极具迷惑性。
- 解决：用 `dangerouslyDisableSandbox: true` 提权执行 `mkdir -p .git/refs/remotes/origin && printf '<sha>\n' > .git/refs/remotes/origin/main`，之后 `[gone]` 消失，跟踪恢复正常。
- **教训**：Git 命令返回 exit=0 不代表真的写成功；遇到 `[gone]` 或引用查不到时，先用 `git for-each-ref` / 直接 `ls .git/refs` 核实文件是否真的存在，再考虑提权。

### 环境坑：MCP `get_file_contents` 读空文件会报 schema 错

- 用 `mcp__github__get_file_contents` 读取 0 字节的 `README.md` 时返回 `invalid_union` / 期望 `text` 的 schema 校验错误。
